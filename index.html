1. OOP-Kernbegriffe

  • Klasse: Bauplan/Schablone (definiert Attribute & Methoden).
  • Objekt / Instanz: Konkretes Ding zur Laufzeit im Speicher.
  • Kapselung: Daten verbergen (__privat), Zugriff über kontrollierte Schnittstellen (Getter/Setter).
  • Abstraktion: Reduktion auf das Wesentliche, Weglassen von Details.
  • Generalisierung / Spezialisierung: Superklasse bündelt Gemeinsames nach oben, Subklasse verfeinert nach unten.
  • Polymorphie: Subklassen überschreiben Methoden; gleicher Aufruf reagiert objektspezifisch unterschiedlich.

2. Python Konstruktor, self & super()

class Fahrzeug:
    art = "Gefährt"                 # Klassenattribut (statisch, 1x pro Klasse)
    def __init__(self, marke: str):
        self.marke = marke          # Instanzattribut (gehört genau diesem Objekt)

class ElektroAuto(Fahrzeug):
    def __init__(self, marke: str, kwh: int):
        super().__init__(marke)     # Delegiert Basisinitialisierung an Elternklasse
        self.kwh = kwh              # Eigene Spezialisierung
        self.aktiv = True           # Fester Startwert (braucht keinen Parameter!)

3. Kapselung, Getter/Setter & Return

class Konto:
    def __init__(self):
        self.__stand = 0.0          # Zwei Unterstriche = PRIVAT

    def get_stand(self) -> float:   # Getter reicht Wert mit 'return' nach draußen
        return self.__stand

    def set_stand(self, betrag: float) -> None: # Setter kontrolliert ("Türsteher")
        if betrag >= 0:
            self.__stand = betrag

4. UML Diagramm-Regeln

Klassendiagramm: • + public, - private, # protected
• /abgeleitet: Berechnet, nicht gespeichert!
• unterstrichen: statisch / Klassenattribut
• ◇ Aggregation: Teil lebt ohne Ganzes weiter.
• ◆ Komposition: Existenzabhängig (stirbt mit).
Use-Case Diagramm: • Akteure immer außerhalb der Grenze!
• <<include>>: Zwingende Pflicht (Pfeil zum Teilschritt).
• <<extend>>: Optionaler Sonderfall (Pfeil zurück zum Basisfall!).
