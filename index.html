📖 Klausur-Spickzettel & Formelsammlung

1. UML-Klassendiagramm Notation

Sichtbarkeiten: • + public (öffentlich)
• - private (privat, in Python __)
• # protected (geschützt, in Python _)
• ~ package (Paket-Sichtbarkeit)
Besondere Attribute: • /abgeleitet: Berechnet, nicht gespeichert!
• unterstrichen: Statisch (Klassenattribut / Klassenmethode)
• kursiv: Abstrakt (Klasse oder Methode)

2. UML Beziehungen (Klausur-Regeln)

  • ◇ Aggregation (weiße Raute): Lose Teil-Ganzes-Beziehung. Das Teil lebt ohne das Ganze weiter. Die Raute steht immer beim Ganzen!
  • ◆ Komposition (schwarze Raute): Strenge Existenzabhängigkeit. Stirbt das Ganze, stirbt das Teil mit. Die Raute steht immer beim Ganzen!
  • ▷ Generalisierung (leere Pfeilspitze): Vererbung ("ist-ein"). Der Pfeil zeigt immer nach oben zur Superklasse.

3. Use-Case (Anwendungsfall) Diagramme

  • Akteure: Stehen ausnahmslos immer außerhalb der Systemgrenze!
  • <<include>>: Zwingender Pflichtschritt. Pfeil zeigt zum Teilschritt.
  • <<extend>>: Optionaler Sonderfall bei Bedingung. Pfeil zeigt zurück zum Basisfall!
