Klausur-Spickzettel & Formelsammlung (LF7 & LF8)

1. UML-Klassendiagramm Notation

Sichtbarkeiten: • + public (öffentlich)
• - private (privat, in Python __)
• # protected (geschützt, in Python _)
• ~ package (Paket-Sichtbarkeit)
Besondere Kennzeichnungen: • /abgeleitet: Berechnet, nicht gespeichert!
• unterstrichen: Statisch (Klassenattribut / Klassenmethode)
• kursiv: Abstrakt (Klasse oder Methode)

2. UML Beziehungen (Klausur-Regeln)

  • ◇ Aggregation (weiße Raute): Lose Teil-Ganzes-Beziehung. Das Teil existiert auch ohne das Ganze weiter. Die Raute steht immer am Ganzen!
  • ◆ Komposition (schwarze Raute): Strenge Existenzabhängigkeit. Stirbt das Ganze, stirbt das Teil mit. Die Raute steht immer am Ganzen!
  • ▷ Generalisierung (leere Dreiecksspitze): Vererbung ("ist-ein"). Der Pfeil zeigt immer nach oben zur Basisklasse.

3. Use-Case (Anwendungsfall) Diagramme

  • Akteure: Stehen ausnahmslos immer außerhalb der Systemgrenze!
  • <<include>>: Zwingend erforderlicher Pflichtschritt. Pfeil zeigt zum Teilschritt.
  • <<extend>>: Optionaler Erweiterungsschritt bei Bedingung. Pfeil zeigt zurück zum Basisfall!
